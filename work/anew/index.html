Anew

项目简介

把一天收敛成一个更容易开始的最小循环。

Anew 是一款 ADHD 友好的每日计划工具，核心目标是：减少开始一件事之前所需要做的决定。通过一次只呈现一件事，降低传统待办清单带来的决策压力，将一天组织为 Pick → Focus → Done → Review 的轻量行动循环，让用户更容易从“计划”进入“行动”。
